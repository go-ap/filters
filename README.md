[![Go Report Card](https://goreportcard.com/badge/github.com/go-ap/filters)](https://goreportcard.com/report/github.com/go-ap/filters)

This project is part of the [GoActivityPub](https://github.com/go-ap) library which helps with creating ActivityPub applications using the Go programming language.

It represents a type safe filter builder for the the storage backends of the library.
It also provides functionality to translate to and from URL query parameters into said filters.
